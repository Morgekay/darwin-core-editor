# Редактор находок Darwin Core

Программа для ведения таблиц находок организмов (по стандарту [Darwin Core](https://dwc.tdwg.org/)) и сохранения их в файлы Excel (.xlsx). Работает локально в браузере, без установки и без интернета; данные никуда не отправляются.

## Возможности
- ~130 терминов Darwin Core с пояснениями на русском (что означает параметр, пример, допустимые значения);
- свои параметры, если в Darwin Core нет подходящего (описание попадает на отдельный лист файла);
- форма «Добавить организм» с выбором файла, в который он попадёт;
- несколько файлов в одном окне; открытие существующих .xlsx и дополнение их;
- добавление, удаление и перестановка столбцов в уже созданном файле (перетаскиванием и кнопками);
- проверка формата дат, координат и чисел; конвертер градусы-минуты-секунды → десятичные градусы; автонумерация `occurrenceID`;
- пустые ячейки при сохранении можно заполнять значением `n/d`.

## Запуск
1. Скачайте репозиторий (**Code → Download ZIP**) и распакуйте.
2. Откройте `index.html` (или `Запустить.bat` в Windows) в **Edge или Chrome**.

В Edge/Chrome кнопка «Сохранить .xlsx» пишет прямо в выбранный файл на диске. В других браузерах файл скачивается.

## Где хранятся данные
Список файлов и введённые записи автоматически сохраняются в браузере (localStorage) на вашем компьютере. Это временное хранилище: окончательный результат сохраняйте кнопкой «Сохранить .xlsx». При очистке данных браузера несохранённое пропадёт.

В .xlsx записываются два листа: `Occurrences_DwC` (данные) и `Описание_полей` (пояснения к столбцам). Другие листы открытого файла при пересохранении не сохраняются.

## Состав
- `index.html`, `app.js` — интерфейс и логика;
- `dwc-terms.js` — справочник терминов Darwin Core с пояснениями (можно править и дополнять);
- `xlsx.full.min.js` — библиотека [SheetJS Community Edition](https://sheetjs.com/) 0.18.5 (лицензия Apache-2.0).
